# Learning Notes

This directory contains exploratory material that supports engineering decisions without defining
the project's normative architecture.

Suitable topics include:

- AI Agent concepts explained through backend and distributed-systems analogies.
- Source-reading notes for LangGraph, OpenAI Agents SDK, OpenHands, and EINO.
- Experiments comparing execution models or provider behavior.
- Lessons learned while implementing each roadmap phase.

Use descriptive filenames such as `agent-loop.md` or `langgraph-state-model.md`. Promote a conclusion
to an ADR when it becomes a durable project decision.
